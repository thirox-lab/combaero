- `MultiPortChamberElement` keeps its loss term when the common port's flow is nearly zero. The compressible reference head was formed as `pow(1 + x, e) - 1`, which rounds to exactly 0 below a Mach number of about 1e-8 (and loses digits well above it), so the loss term (85 Pa on the reproducer) dropped out of the residual while the Jacobian kept its analytic slope (1.7e11 against a finite difference of 0). It is now `expm1(e log1p(x))`; above a common-port Mach number of about 1e-3 the old form's cancellation was small (4e-10 relative at 1e-3), so the residual barely changes there (#1252, #1247).
- The Jacobian of a network in which a mass-flow boundary is read before it has taken a reversed stream in the propagation order no longer carries that stream's mixing sensitivities: the residual reads the boundary's own fixed gas there, and the relay now does too (1.85e12 against a finite difference of 0 on a splitter outlet's channel, #1253).
