- **`combustor_residuals_and_jacobians` no longer takes `P` (#1272).** The burn's pressure has to be the streams' mixed Pt, the one pressure its stream partials are those of (#1244), and the kernel computes that itself. Since #1271 every other P was refused, so the argument could only be the value the kernel already had. It is now taken from the streams.
  - The Python binding's arguments after `streams` are keyword-only, so an old call that passes P positionally raises `TypeError` rather than reading it as `Q`.
  - `kCombustorPressureMatchRtol` is removed.
  - `CombustorNode` results are unchanged: it passed exactly that mixed Pt.
