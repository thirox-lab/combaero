- **Hole-Cd range flags now name the variable and are reported as information, never as warnings.** Every orifice-family element now reports `Cd_extrapolated_Re`, `Cd_extrapolated_l_d` and `Cd_extrapolated_edge` alongside `Cd_in_range`; the C++ side is `discharge_cd_envelope`. A thick Idelchik hole beyond l/d 4 now reads `Cd_extrapolated_l_d` and no longer looks like a blanket miss. No Cd value changes: networks are bit-identical. The flags themselves change as follows:
  - Lichtarowicz is no longer flagged above Re 2e4, because there it sits at its own Eq. (7) high-Re asymptote.
  - McGreehan-Schotsch is now flagged beyond l/d 10. That is the end of the data its length function was fitted to; the function keeps falling beyond it (Cd 0.49 at l/d 40).
- **McGreehan-Schotsch below Re 1e4 no longer prints a C++ warning on every Cd evaluation.** The held value is now reported as `Cd_extrapolated_Re`.
- **The Rogers & Hersh crossflow Cd now has an envelope flag.** `ImpingementPlateElement` and `ImpingementArray` report `Cd_crossflow_extrapolated_velocity_ratio`, `_l_d` and `_grazing_velocity` wherever the law acts; the C++ side is `rogers_hersh_1976_envelope`, covering CR-2681's Vi/V_inf 0.004-0.9, L/D 0.12-2.0 and V_inf 24-85 m/s. `EffusionLiner` reports any panel's `Cd_extrapolated_Re` and `Cd_extrapolated_l_d`.
