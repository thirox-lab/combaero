- **The source register records a SHA-256 per document (#1057).** Every `validation/sources.yaml` entry has a `sha256` field. `scripts/sources.py check` verifies each one against `sources/` and also reports the same document registered under two names. `sources/` is backed up outside git, so these hashes prove that a restore came back byte-identical. `sources.py new` writes the hash into the stub, and `sources.py hash --write` fills in missing ones but never overwrites a mismatch. CI, which has no `sources/`, checks that every entry carries a well-formed hash.
