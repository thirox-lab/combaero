- **Building combaero from source no longer downloads googletest (#1059).** The Python build already passed `-DCOMBAERO_ENABLE_TESTS=OFF`, but `CMakeLists.txt` never read that option, so every `pip install` from the sdist fetched googletest from GitHub's archive host. That made installs fail while the host was down, and CI did fail on HTTP 503/504 on 2026-11-08. The option now gates the googletest fetch and the C++ test targets. It defaults to ON, so `cmake -B build && ctest` is unchanged.
