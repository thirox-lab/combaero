- **The GUI carries a hole node's discharge coefficient as one `hole_cd` object, the library's `HoleCd` field for field (#1098).** The orifice, effusion plate, film cooling, slot film, impingement array and effusion liner nodes each have `hole_cd` (`correlation`, `Cd`, `inclination`, `inlet_crossflow`, `exit_crossflow`); the backend validates it as `HoleCd` does and builds the element with it unchanged, so a new `HoleCd` option reaches every hole node without edits. The exit term's region and compound angle stay on the node.
  - **The Inspector edits it as one "Hole Cd" section.** Each select offers only what that node type builds, and every "auto" option names what it resolves to on that node (for example "Auto: none (shaped hole)" for the inclination of the default film row). The Cd field shows for `fixed` only. Switching the correlation resets a forced term the new one cannot take to "auto", and drops the Cd unless the correlation is `fixed`.
  - **New on the effusion liner:** its panels' correlation, inclination, supply crossflow (`"none"` takes the duct as a plenum) and Rowbury exit term. "auto" everywhere is the liner as before.
  - **File version 1.3.** A file saved by v0.11.1 or earlier carries `correlation`, `Cd` and (impingement array) `cd_crossflow` on the node; they are lifted into `hole_cd` on load, by the backend and the GUI alike, and solve to the same result (F, J and the solution bit for bit over every shipped example and a set of legacy files covering each hole node type and option). A node with both the old fields and `hole_cd` is refused. `cd_crossflow` is lifted on the impingement array only; on any other node it is ignored, as v0.11.1 ignored it. The shipped examples are migrated.
  - **Refused on load, with a message naming the fix:** the pre-release node keys `cd_inclination` and `cd_exit_crossflow` of development builds (they belong in `hole_cd.inclination` / `hole_cd.exit_crossflow`; the GUI's load notice lists them too), a key `HoleCd` does not have inside `hole_cd` (a misspelling), a fixed `Cd` that is not positive and finite (a 0 used to fail as a division by zero), a slot's `Cd` above 1 (its v0.11.1 bound), and a removed correlation (Miller, Stolz), whose message names the replacement for that node type.
  - **A `fixed` hole_cd without a `Cd`** builds with the element's default where it has one (Florschuetz's 0.79 on the impingement array) and is refused elsewhere; the Inspector shows the field empty, with that default as its placeholder or a note that a value is needed. Switching away from `fixed` and back restores the Cd last entered on that node in the session.
