- **The incompressible channel's state partials are exact (#1211).** `channel_residuals_and_jacobian` differentiated its friction drop by differences of the whole drop for the upstream static pressure, Tt and composition columns.
  - **Before:** the composition columns used a forward difference, up to 6e-6 off. P and Tt used central differences. A call cost 4 + n_species extra drop evaluations.
  - **Now:** all three use the chain rule through rho and mu: `Re = |m| D / (mu A)` holds no rho, so `d dP = (L/D) m|m| / (2 rho A^2) f'(Re) dRe - dP drho / rho`, with `dRe = -Re dmu / mu`. They match resolved differences to 1e-8 (P, Tt) and 1e-7 (each species, absent ones included), and a call is about 8-10x faster.
  - The drop itself, and so every residual, is unchanged.
  - The composition columns are derivatives in the raw Y the kernel reads, which a Newton iterate need not sum to 1: `normalize_fractions` divides by the clamped sum S, so each column is the along-simplex gradient over S (0 for a fraction clamped at a negative value), as the forward difference had it.
