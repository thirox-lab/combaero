- **An unknown `friction_model` is refused instead of making a frictionless duct (#1213).** `ChannelElement(friction_model="Haaland")`, or any tag that is not a registered model, used to solve with f = 0, because the C++ dispatcher returned 0 with a validity flag that every caller dropped. A lone 1 m duct then passed twice the flow of `"haaland"`, with no warning.
  - **At construction:** `ChannelElement`, `CrossflowSegmentElement` and `ImpingementCrossflowElement` raise `ValueError`, naming the element and the valid tags.
  - **In the kernels:** `friction_and_jacobian` and every bound kernel that takes a friction tag raise `ValueError` at any flow. Before, only the zero-flow branch raised.
  - The registered tags are unchanged: "haaland", "serghides", "colebrook" and "petukhov".
