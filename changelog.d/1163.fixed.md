- A network with a `FuelBoundary` now starts every solve, retry and stage from a point set by its inputs alone, whatever was evaluated before (#1163). The cold-start mass-flow estimates read the fuel controller's `m_dot`, which holds the solver's last iterate, so a start built after an evaluation took the fuel flow that evaluation left behind. On a compressor-burner-turbine cycle, a 6e-17 kg/s change left by a failed stage decided whether the next stage converged. The estimates now take a controller's `m_dot_guess` (0 without one). This is what a fresh network holds, so the first start of a solve is unchanged. A controller without `m_dot_guess` fed from a pressure boundary changes, though: its fuel-fixed stage runs first, and that stage's inner start no longer adds the fuel's start flow to the flows downstream of the combustor. On 140 stress draws the same draws converge, and two refused draws report a different failure kind. The ejector's closed-form seed reads the same given flow. The homotopy start (`init_strategy="homotopy"`) now also restores every `MassFlowBoundary` flow when a rung raises; it used to leave them at a fraction of the user's value.
