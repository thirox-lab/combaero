- **The GUI carries a hole node's discharge coefficient as one `hole_cd` object, the library's `HoleCd` field for field (#1098).** The orifice, effusion plate, film cooling, slot film, impingement array and effusion liner nodes each have `hole_cd` (`correlation`, `Cd`, `inclination`, `inlet_crossflow`, `exit_crossflow`); the backend validates it as `HoleCd` does and builds the element with it unchanged, so a new `HoleCd` option reaches every hole node without edits. The exit term's region and compound angle stay on the node.
  - **The Inspector edits it as one "Hole Cd" section.** Each select offers only what that node type builds, and every "auto" option names what it resolves to on that node (for example "Auto: none (shaped hole)" for the inclination of the default film row). The Cd field shows for `fixed` only. Switching the correlation resets a forced term the new one cannot take to "auto", and drops the Cd unless the correlation is `fixed`.
  - **New on the effusion liner:** its panels' correlation, inclination, supply crossflow (`"none"` takes the duct as a plenum) and Rowbury exit term. "auto" everywhere is the liner as before.
  - **File version 1.3.** A file saved by v0.11.1 or earlier carries `correlation`, `Cd` and (impingement array) `cd_crossflow` on the node; they are lifted into `hole_cd` on load, by the backend and the GUI alike, and solve to the same result (F, J and the solution bit for bit over every shipped example and a set of legacy files covering each hole node type and option). A node with both the old fields and `hole_cd` is refused. The shipped examples are migrated.
